# Portfolio Media

- `public/images/<project>/`: website-ready assets, tracked in Git and deployed. Use real files here, never links to folders outside the repository.
- Project working media: originals, CAD, source videos, and private test captures stay with their project. Selected exports are copied into `public/images` deliberately.
- `local-media/autonomous-rover/`: local-only originals for the rover, which has no separate source repository established here.
- Notebook's `career/portfolio/project-media/`: local shortcuts to project originals and `website-ready` copies, not another media store.

Preserve simulation labels and image aspect ratios. Do not publish controller logs, credentials, or whole working-media folders. Local-only originals need a separate backup; Git covers published assets, not ignored files.
